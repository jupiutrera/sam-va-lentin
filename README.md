# 💝 Página de San Valentín para Paula

Una página web interactiva de San Valentín creada con React, Vite y Framer Motion.

## ✨ Características

- 🎨 **5 Secciones Animadas**:
  1. Vista inicial con corazones flotantes
  2. Cronograma vertical del tiempo juntos
  3. Pregunta interactiva con botón "No" que se escapa
  4. Carta de amor con animaciones suaves
  5. Quiz interactivo con puntuación

- 🚀 **Tecnologías Modernas**:
  - **React 18** - Framework UI
  - **Vite** - Build tool ultra-rápido
  - **Framer Motion** - Animaciones profesionales
  - **CSS Módulos** - Estilos encapsulados

- 📱 **Diseño Responsive**: Optimizado para visualización móvil

## 🛠️ Instalación y Configuración

### Prerrequisitos
- Node.js (versión 18 o superior)
- npm o yarn

### Pasos para ejecutar localmente

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Ejecutar en modo desarrollo**:
   ```bash
   npm run dev
   ```
   La aplicación estará disponible en `http://localhost:5173`

3. **Build para producción**:
   ```bash
   npm run build
   ```

4. **Preview del build**:
   ```bash
   npm run preview
   ```

## 🚀 Deploy a GitHub Pages

### Usando gh-pages (Recomendado)

1. Ejecutar el comando de deploy:
   ```bash
   npm run deploy
   ```

2. Configurar GitHub Pages:
   - Ve a Settings → Pages en tu repositorio
   - En "Branch" selecciona `gh-pages`
   - Guarda los cambios

3. Tu página estará disponible en:
   ```
   https://jupiutrera.github.io/sam-va-lentin/
   ```
